- `index.html`: estructura de la experiencia.

- `app.js`: datos inyectados, render de módulos, gráficas y microinteracciones.
- `SECURITY.md`: notas de seguridad enterprise.
- `data/`: CSVs y especificaciones fuente usadas para la inyección.

## Capa enterprise agregada

Cada módulo conserva sus KPIs consolidados originales y ahora agrega una vista de detalle:

- Filtros por `Global`, marca, sucursal o estado operativo.
- Cards por unidad / campaña / proyecto / fuente.
- Comparativos visuales por periodo, estatus o rendimiento.
- Tabla ejecutiva con trazabilidad.
- Notas de disponibilidad de datos para no inventar información.

Los módulos actuales son Finanzas, Operaciones, Marketing, Recursos Humanos, Expansión y Excelencia de Marca. También se incluye la sección `Pendientes Importantes` para temas ejecutivos fuera del tracker formal de compromisos.
