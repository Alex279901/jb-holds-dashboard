Nota metodológica

Este módulo usa Margen Neto (Utilidad Neta / Ventas Totales) como métrica de rentabilidad principal. La métrica de rentabilidad es el Margen Neto (Utilidad Neta / Ventas Totales), que refleja la ganancia real después de todos los costos de operación disponibles en los estados financieros actuales. Los datos son demo V1 y están preparados para conectarse a Google Sheets mediante Apps Script en una fase posterior.
